# Roles Reversed Wolf

Браузерная игра для FEIS Game Jam на тему **Roles Reversed**.

Игрок управляет волком, который маскируется под овцу. Днём он пытается не выдать себя среди стада, а ночью привычные роли охотника и добычи меняются.

## Статус

Подготовлена структура проекта. Игровая реализация ещё не начата.

## Структура

- `src/` — исходный код игры.
- `public/assets/` — оптимизированные файлы, которые загружает браузер.
- `art-source/` — редактируемые исходники собственных моделей и текстур.
- `docs/design/` — актуальные правила и решения по игре.
- `docs/submission/` — материалы для страницы джема и сдачи.
- `tests/` — автоматические и ручные проверки.
- `ASSETS.md` — происхождение и лицензии всех сторонних материалов.
- `AI_USAGE.md` — обязательный отчёт об использовании ИИ.

## Разработка

Технологический стек и команды запуска будут добавлены вместе с первым работающим прототипом.
