# Roles Reversed Wolf

Небольшая браузерная 3D-игра для FEIS Game Jam на тему **Roles Reversed**.

Игрок управляет волком, который маскируется под овцу. Днём он смешивается со стадом и выбирает момент для охоты. Ночью сторожевой пёс становится активнее, и привычный охотник сам превращается в добычу.

## Текущий прототип

- одна игровая карта и плавная перспективная камера с вращением, наклоном, масштабом и слежением;
- временные скелетные 3D-модели с переключением анимаций по состояниям;
- плавное управление волком относительно камеры, ускорение, инерция, рывок и столкновения с крупными препятствиями;
- восемь овец со стайным поведением: выпас, блуждание, разделение, сближение и паника;
- пугливая овца с колокольчиком и приманивание одной овцы блеянием;
- надевание и снятие маскировки за три секунды неподвижности;
- день, сумерки, ночь и рассвет;
- зрение, подозрение, патруль, погоня, последняя виденная точка и поиск собаки по локальному запаху;
- ночной соперник, который самостоятельно выбирает овцу, несёт её к выходу и может быть перехвачен;
- безвозвратная потеря овцы после завершённого ухода соперника;
- пастух с расписанием, собственным зрением, патрулём, предупреждением о выстреле и перезарядкой;
- постоянное снижение максимального здоровья после укуса;
- перенос овцы в зубах, её сброс при рывке или ударе, короткое поедание и лечение;
- три состояния овечьей шкуры, ремонт у сарая и притворный выпас;
- слух на рывки, схватки и поедание, а также координация собаки с пастухом;
- последовательные ночные вторжения, рост охраны по дням и лимит в три дня;
- победа только после выполнения квоты и пережитого рассвета;
- читаемая подготовка атаки соперника и сбивание его добычи рывком;
- пауза по `Escape` и автопауза при смене окна;
- обычные раны от соперника и лечение едой только до действующего максимума;
- победа, поражение и повтор забега;
- адаптивный интерфейс на русском языке.

Часть графики текущей версии — временная процедурная геометрия. Персонажи используют временные скелетные модели, а финальные модели можно подключить без изменения основной логики.

## Временные модели и замена

- игрок: `public/assets/models/wolf.gltf`;
- сторожевой пёс: `husky.gltf`;
- соперник: `fox.gltf`;
- овцы: `sheep-placeholder.gltf` (сейчас анимированная альпака, пока нет финальной овцы);
- нейтральные обитатели: `donkey.gltf` и `cow.gltf`, самостоятельно бродят и убегают от раскрытого волка;
- дальний фон фермы: `farmyard.glb`;
- пастух пока процедурный: подходящей человеческой модели в наборе нет.

Модели свинки в предоставленной папке нет, поэтому выдуманный заменитель в сборку не добавлялся.

Каждая модель подключена к логическому корню персонажа, поэтому коллизии, ИИ и игровые координаты не зависят от геометрии. Для финальной замены достаточно заменить файл, отрегулировать `targetHeight`/поворот в `loadModels()` и сопоставить названия клипов в `updateRigAnimations()`.

## Управление

- `WASD` или стрелки — движение относительно текущего направления камеры;
- нажать `Shift` во время движения — короткий направленный рывок с перезарядкой;
- удерживать `F` три секунды без движения — переодеться;
- `Пробел` без маскировки — забрать ближайшую овцу или ударить соперника;
- удерживать `E` с овцой — съесь её; в шкуре у сарая — починить маскировку;
- `G` в шкуре без движения — притвориться пасущейся овцой;
- `Q` в шкуре — подманить одну спокойную овцу;
- `Z` / `X` или перетаскивание мышью — повернуть и наклонить камеру;
- колесо мыши — приблизить или отдалить камеру;
- `Escape` — пауза;
- `R` после завершения — вернуться к началу.

## Локальный запуск

```bash
npm install
npm run dev
```

Для итоговой сборки:

```bash
npm run build
```

Готовые файлы появятся в `dist/`. Для itch.io содержимое этой папки упаковывается в ZIP так, чтобы `index.html` находился в корне архива.

## Структура

- `src/` — код и стили игры;
- `public/assets/` — оптимизированные модели, текстуры, звук и UI для браузера;
- `art-source/` — редактируемые исходники собственных моделей и текстур;
- `docs/design/` — актуальные правила и статус;
- `docs/submission/` — материалы для страницы джема;
- `tests/` — проверки;
- `ASSETS.md` — происхождение и лицензии материалов;
- `AI_USAGE.md` — отчёт об использовании ИИ.
