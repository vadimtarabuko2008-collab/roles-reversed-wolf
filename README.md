# Roles Reversed Wolf

Небольшая браузерная 3D-игра для FEIS Game Jam на тему **Roles Reversed**.

Игрок управляет волком, который маскируется под овцу. Днём он смешивается со стадом и выбирает момент для охоты. Ночью сторожевой пёс становится активнее, и привычный охотник сам превращается в добычу.

## Текущий прототип

- одна игровая карта и фиксированная изометрическая камера;
- управление волком с клавиатуры;
- восемь овец с простым автономным движением и реакцией на открытого волка;
- надевание и снятие маскировки за три секунды неподвижности;
- день, сумерки, ночь и рассвет;
- патрулирование, обнаружение, погоня и укусы сторожевой собаки;
- постоянное снижение максимального здоровья после укуса;
- победа, поражение и повтор забега;
- адаптивный интерфейс на русском языке.

Вся графика текущей версии — временная процедурная геометрия. Финальные модели будут подключаться без изменения основной логики.

## Управление

- `WASD` или стрелки — движение;
- удерживать `F` три секунды без движения — переодеться;
- `Пробел` рядом с овцой без маскировки — забрать добычу;
- `R` после завершения — вернуться к началу.

## Локальный запуск

```bash
npm install
npm run dev
```

Для итоговой сборки:

```bash
npm run build
```

Готовые файлы появятся в `dist/`. Для itch.io содержимое этой папки упаковывается в ZIP так, чтобы `index.html` находился в корне архива.

## Структура

- `src/` — код и стили игры;
- `public/assets/` — оптимизированные модели, текстуры, звук и UI для браузера;
- `art-source/` — редактируемые исходники собственных моделей и текстур;
- `docs/design/` — актуальные правила и статус;
- `docs/submission/` — материалы для страницы джема;
- `tests/` — проверки;
- `ASSETS.md` — происхождение и лицензии материалов;
- `AI_USAGE.md` — отчёт об использовании ИИ.
