# Состояние проекта

Обновлено: 26 октября 2026 года.

## Текущий этап

Создан чистый корень проекта и локальный репозиторий Git с веткой `main`. Коммитов пока нет. Игровая реализация ещё не начата.

## Подтверждённые решения

- Тема джема: Roles Reversed.
- Конкурсная версия запускается в браузере.
- До получения финальных моделей игра собирается на временной геометрии.
- Укус собаки оставляет постоянную рану до конца забега; остальные раны можно лечить.
- Овца, унесённая чужим волком, теряется навсегда, и идеальная победа становится недоступна.
- Допустимы стилизованные атаки, смерть и небольшие эффекты крови без расчленения и натурализма.

## Работа с материалами

Исходные референсы и скачанные наборы не копируются в репозиторий автоматически. Сначала проверяются формат, необходимость и лицензия. Использованные материалы помещаются в подходящую папку проекта и сразу записываются в `ASSETS.md`.
