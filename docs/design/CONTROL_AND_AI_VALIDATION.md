# Проверка управления и ИИ

Последний полный прогон: 26 октября 2026 года.

## Управление

| Проверка | Ожидаемый результат | Результат |
|---|---|---|
| Короткое нажатие `Space` | действие фиксируется даже между кадрами; при неверном контексте появляется объяснение | пройдено |
| Короткое нажатие `Q` | приманка срабатывает один раз и запускает перезарядку | пройдено |
| Короткое нажатие `E` | игра объясняет, нужна ли добыча, остановка или сарай | пройдено |
| `G` | выпас работает только в шкуре, без движения и без добычи | пройдено |
| `F`, удержание 3 секунды | маскировка меняется только после полной остановки | пройдено |
| `Shift` во время движения | один направленный рывок, шум и перезарядка; удержание не повторяет рывок автоматически | пройдено |
| `WASD` после поворота камеры | `W` всегда ведёт вперёд по экрану, остальные направления сохраняют ту же систему | пройдено |
| Мышь, колесо, `Z/X` | вращение, наклон и масштаб камеры не ломают направление движения | пройдено |
| `Escape` | пауза останавливает симуляцию, продолжение сохраняет забег | пройдено |

## Поведение персонажей

| Система | Проверенное поведение |
|---|---|
| Волк | инерция, плавный разворот, фиксированное направление рывка, динамический отъезд камеры |
| Стадо | разделение, сближение, выпас, приманивание, бегство и распространение паники на соседей |
| Пёс | патруль, подозрение, реакция на шум, распознавание открытого волка и неестественного рывка в шкуре, перехват по прогнозируемой позиции, визуальный и запаховый поиск |
| Соперник | выбор менее защищённой овцы, унос к ближайшему выходу, уклонение от пса, атака с предупреждением и отступление |
| Пастух | расписание, патруль, реакция на тревогу пса, линия видимости, предупреждение выстрела и перезарядка |
| Осёл и корова | независимое блуждание, остановки и бегство от раскрытого волка |

## Техническая проверка

- `npm run typecheck` — пройдено;
- `npm run build` — пройдено;
- загрузка всех GLTF/GLB — пройдена;
- ошибки и предупреждения выполнения в консоли браузера — отсутствуют;
- дневная и ночная фазы, появление соперника и смена освещения — пройдены.

## Ограничения временной версии

- альпака используется вместо финальной овцы;
- подходящей модели свинки в предоставленном наборе нет;
- пастух остаётся процедурной моделью до предоставления человеческой модели;
- лицензии временных моделей необходимо подтвердить перед конкурсной публикацией.
